## ما هو Saudi HR؟

**Saudi HR** تطبيق موارد بشرية وامتثال سعودي يعمل داخل ERPNext. يجمع بيانات الموظف وعقده وحضوره وإجازاته وراتبه ووثائقه في سجل تشغيلي واحد، ولا يتطلب تثبيت HRMS.

> **الموظف ليس صفًا في جدول.** كل حركة في ملفه تؤثر في استحقاق أو التزام أو قرار يحتاج إلى تفسير ومراجعة.

يعطي التطبيق فريقك صورة واحدة عن الحدث وسببه ومسؤول الإجراء التالي. تبدأ الرحلة من طلب التوظيف، وتستمر حتى المخالصة ومكافأة نهاية الخدمة.

### ما تحصل عليه

- **تجربة عربية:** واجهات ومصطلحات واتجاه كتابة من اليمين إلى اليسار
- **ملف موظف شامل:** الهوية والعمل والعقد والوثائق والحضور والراتب في سياق واحد
- **تشغيل مستقل:** وظائف الموارد البشرية الأساسية دون الاعتماد على HRMS
- **سياسات دقيقة:** تخصيص الإجازات حسب الشركة أو القسم أو الموظف
- **رواتب قابلة للمراجعة:** استيراد Excel مع التحقق من الإضافي والخصومات وصافي الراتب
- **امتثال موثق:** مسؤوليات ومواعيد وأدلة وسجل تغييرات قابل للتدقيق

> [!IMPORTANT]
> يساعد التطبيق على تشغيل إجراءات مستندة إلى متطلبات العمل السعودي. راجع المستشار القانوني عند تفسير حالة خاصة أو اعتماد قرار نظامي.

## دورة الموظف داخل النظام

يربط التطبيق مراحل دورة الموظف بدل توزيعها على ملفات وقوائم منفصلة.

| المرحلة | السجلات والإجراءات | النتيجة التشغيلية |
|:--|:--|:--|
| **1. التخطيط والتوظيف** | طلب التوظيف، المرشح، المقابلة، التقييم والعرض | قرار توظيف موثق |
| **2. العقد والتهيئة** | العقد، فترة التجربة، الوثائق، العهد وخطة الانضمام | بداية عمل مكتملة |
| **3. الحضور والإجازات** | الوردية، الموقع، البصمة، الغياب وسياسة الإجازة | استحقاق يومي قابل للتفسير |
| **4. الرواتب والالتزامات** | المسير، الإضافي، الخصومات، القروض، التأمينات وحماية الأجور | راتب محسوب وقابل للمراجعة |
| **5. العلاقات والامتثال** | السياسات، الإقرارات، التحقيقات، التظلمات والتفتيش | إجراء له مسؤول وموعد ودليل |
| **6. نهاية الخدمة** | الإنهاء، الإخلاء، المقابلة، المكافأة والمخالصة | خروج مكتمل دون سجلات معلقة |

## القدرات الرئيسية

| المجال | ما يدعمه التطبيق |
|:--|:--|
| **ملف الموظف** | البيانات الشخصية والوظيفية، العقد، الراتب، الوثائق، العهد والسجل الزمني |
| **التوظيف** | الاحتياج، المرشحون، المقابلات، العروض، التهيئة وفترة التجربة |
| **العقود** | العقود المحددة وغير المحددة، التجديد، التنبيهات والتاريخ التعاقدي |
| **الحضور** | الورديات، الحضور المحمول، المواقع، التأخر، الغياب والتسويات |

| **نهاية الخدمة** | الإنهاء، الإخلاء، المقابلة، المكافأة والمخالصة النهائية |

## استيراد الرواتب من Excel

يدعم مسير الرواتب القالب المعتمد والقوالب القديمة المتداولة لدى العملاء. يعرض التطبيق معاينة قبل الحفظ حتى تراجع النتائج دون تغيير المسير.

يتحقق الاستيراد من:

- مطابقة الموظف بالرقم الوظيفي ثم الحقول البديلة المعتمدة
- الإضافي والخصومات والراتب الإجمالي وصافي الراتب
- الأعمدة الإلزامية والقيم السالبة والمعادلة المحاسبية
- الصفوف المتطابقة، مع احتساب قيمها مرة واحدة
- الأسماء غير المرتبطة، مع تقرير فجوات وخيار إنشاء الموظفين وفق الإعدادات
- مراكز التكلفة والأقسام قبل إنشاء سجلات الرواتب

نزّل القالب من شاشة **مسير الرواتب الشهري السعودي**، ثم نفّذ **معاينة الملف** قبل **استيراد الملف المرفق**.

## التثبيت

هذه الحزمة مخصصة لـ **ERPNext v15**. الإصدار المختبر هو Saudi HR `1.19.3`، ويحمل وسم `v1.19.3`.

### المتطلبات

- موقع ERPNext v15 يعمل قبل تثبيت التطبيق
- صلاحية تشغيل أوامر Bench على الخادم
- نسخة احتياطية قبل التثبيت على موقع إنتاجي

نفّذ الأوامر التالية من مجلد Bench. تستنسخ الأوامر فرع v15، وتثبّت التطبيق، ثم تطبق مخطط قاعدة البيانات وتبني الأصول.

```bash
cd ~/frappe-bench
bench get-app --branch version-15 \
  https://github.com/ahmadmdm/hr-saudi-arabia-erpnext.git
bench --site erp.example.com install-app saudi_hr
bench --site erp.example.com migrate
bench build --app saudi_hr
bench restart
```

افتح المسارات التالية بعد اكتمال التثبيت:

| المسار | الاستخدام |
|:--|:--|
| `/app/saudi-hr` | مساحة العمل الرئيسية |
| `/app/professional-hr-hub` | مركز تشغيل الموارد البشرية |
| `/app/attendance-action-hub` | مراجعة الحضور واتخاذ الإجراء |
| `/mobile-attendance` | تسجيل الحضور من الجوال |

> [!TIP]
> لتثبيت التطبيق على ERPNext v16، استخدم [فرع version-16](https://github.com/ahmadmdm/hr-saudi-arabia-erpnext/tree/version-16) واتبع [دليل التثبيت](docs/installation.md).

## شغّل أول سيناريو تجريبي

استخدم شركة وموظفًا تجريبيين قبل إدخال بيانات الإنتاج. يختبر هذا السيناريو الترابط بين الملف والعقد والحضور والإجازة والراتب.

1. **أنشئ الهيكل:** أضف الشركة والفرع والقسم والوظيفة والموقع
2. **اضبط السياسات:** عرّف الوردية والإجازات ونوع العقد وتنبيهات الوثائق
3. **أضف موظفًا:** أكمل هويته ووظيفته وعقده ووثائقه ومكونات راتبه
4. **سجّل الحركة:** أضف حضورًا وتأخرًا أو إضافيًا، ثم قدّم طلب إجازة واعتمده
5. **أنشئ المسير:** راجع أثر الحضور والإجازة والإضافي والخصومات على الراتب
6. **راجع الامتثال:** افحص التنبيهات والمستندات المستحقة وسجل الأدلة
7. **اختبر الخروج:** أنشئ إنهاء خدمة تجريبيًا وراجع المكافأة والمخالصة

يوضح [دليل البيانات التجريبية](docs/demo-data.md) القيم المقترحة والنتائج المتوقعة. يعرض [دليل التشغيل الحي](https://ahmadmdm.github.io/hr-saudi-arabia-erpnext/#tutorial) المسار حسب الدور.

## الجودة والحدود التشغيلية

يشمل فحص الجودة التحقق البنيوي، وفحص Python، واختبارات التطبيق، وسلامة فروق Git.

```bash
python scripts/validate_quality.py
ruff check saudi_hr --select F
pytest -q
git diff --check
```

ضع الحدود التالية ضمن خطة التشغيل:

- يحتاج الربط الحي مع قوى والتأمينات ومدد ومقيم إلى بيانات اعتماد وقنوات معتمدة من كل جهة
- يجهز التطبيق المخرجات الحكومية للمراجعة، ولا يرسلها إلى الجهة دون تكامل معتمد
- تحمي صلاحيات المستندات والسجلات بيانات الرواتب والملف الشامل، ويجب مراجعتها قبل الإنتاج
- تراقب المهام المجدولة العقود والإقامات والتصاريح والمهل، ويجب مراقبة العامل المجدول في الخادم
- لا يستبدل التطبيق المراجعة القانونية أو المحاسبية للحالات غير القياسية
